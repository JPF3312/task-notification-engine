# Asynchronous Task Execution & Notification Engine

An event-driven microservice built with Node.js, Express, BullMQ, Redis, PostgreSQL, and WebSockets. Designed to handle background job processing and deliver real-time progress updates to clients.

## Architecture & Tech Stack

- **Backend Framework:** Node.js, Express
- **Message Broker & Task Queue:** Redis, BullMQ
- **Database:** PostgreSQL (Task state persistence)
- **Real-Time Communication:** WebSockets (Socket.io)
- **Testing & CI:** Jest, Supertest, GitHub Actions
- **Containerization:** Docker & Docker Compose
